Integrais

Integração indefinida, definida, por partes e aplicações geométricas.

O que é integração?

Integrar é o processo inverso de derivar. Dado que F'(x) = f(x), chamamos F(x) de primitiva ou antiderivada de f(x). A integral indefinida representa toda a família de primitivas de uma função, diferenciadas por uma constante C.

Já a integral definida tem interpretação geométrica direta: representa a área com sinal entre o gráfico de f(x) e o eixo x no intervalo [a, b].

Integral definida — Teorema Fundamental do Cálculo

∫ₐᵇ f(x) dx = F(b) − F(a)

Esse resultado — chamado Teorema Fundamental do Cálculo — conecta derivação e integração, mostrando que são operações inversas.

Tabela de integrais básicas

Potência (n ≠ −1)
∫ xⁿ dx = xⁿ⁺¹/(n+1) + C
1/x
∫ (1/x) dx = ln|x| + C
Exponencial
∫ eˣ dx = eˣ + C
Seno
∫ sen(x) dx = −cos(x) + C
Cosseno
∫ cos(x) dx = sen(x) + C
Tangente
∫ tg(x) dx = ln|sec(x)| + C
sec²(x)
∫ sec²(x) dx = tg(x) + C
Arctangente
∫ 1/(1+x²) dx = arctg(x) + C

Integração por partes

Técnica usada quando o integrando é produto de duas funções. A fórmula é derivada da regra do produto da derivação:

∫ u dv = uv − ∫ v du

Para escolher bem u e dv, use a ordem de prioridade LIATE: Logarítmica → Inversa trigonométrica → Algébrica → Trigonométrica → Exponencial. Escolha u como o primeiro tipo presente nessa lista.

Exemplo — integração por partes

Calcule ∫ x · eˣ dx:

u = x → du = dx  |  dv = eˣ dx → v = eˣ

∫ x eˣ dx = x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C = eˣ(x − 1) + C

Área entre duas curvas

Quando f(x) ≥ g(x) em todo o intervalo [a, b], a área compreendida entre as duas curvas é calculada por:

A = ∫ₐᵇ [f(x) − g(x)] dx

Volume de sólido de revolução

Ao girar a região sob f(x) em torno do eixo x, o volume do sólido gerado é:

V = π · ∫ₐᵇ [f(x)]² dx
