Exercícios

Questões de derivadas e integrais com resolução passo a passo. Clique em "Ver resolução" para conferir.

Derivadas

Exercício 1
Calcule f'(x) para f(x) = 4x³ − 3x² + 7x − 2

Aplica-se a regra da potência termo a termo:

— Derivada de 4x³ = 3 · 4x² = 12x²

— Derivada de −3x² = 2 · (−3)x = −6x

— Derivada de 7x = 7

— Derivada de −2 (constante) = 0

f'(x) = 12x² − 6x + 7
Exercício 2
Calcule a derivada de g(x) = eˣ · sen(x)

Usa-se a regra do produto: (uv)' = u'v + uv'

— u = eˣ → u' = eˣ

— v = sen(x) → v' = cos(x)

g'(x) = eˣ · sen(x) + eˣ · cos(x) = eˣ(sen x + cos x)
Exercício 3
Calcule h'(x) para h(x) = ln(x² + 1)

Trata-se de uma função composta. Usa-se (ln u)' = u'/u

— u = x² + 1 → u' = 2x

h'(x) = 2x / (x² + 1)
Exercício 4
Calcule a derivada de p(x) = cos(3x²)

Usa-se a regra da cadeia: (cos u)' = −sen(u) · u'

— u = 3x² → u' = 6x

p'(x) = −sen(3x²) · 6x = −6x · sen(3x²)
Exercício 5
Calcule a derivada de q(x) = (2x + 1)⁵

Usa-se a regra da potência composta: (uⁿ)' = n·uⁿ⁻¹·u'

— u = 2x + 1 → u' = 2

— n = 5

q'(x) = 5(2x + 1)⁴ · 2 = 10(2x + 1)⁴

Integrais

Exercício 6
Calcule ∫ (3x² + 2x − 5) dx

Integra-se cada termo usando ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C

— ∫ 3x² dx = x³

— ∫ 2x dx = x²

— ∫ −5 dx = −5x

∫ (3x² + 2x − 5) dx = x³ + x² − 5x + C
Exercício 7
Calcule ∫₀² (x² + 1) dx

Passo 1 — encontrar a primitiva: F(x) = x³/3 + x

Passo 2 — aplicar o Teorema Fundamental: F(2) − F(0)

— F(2) = 8/3 + 2 = 14/3

— F(0) = 0

∫₀² (x² + 1) dx = 14/3 ≈ 4,67
Exercício 8
Calcule ∫ x · cos(x) dx

Usa-se integração por partes: ∫ u dv = uv − ∫ v du

— u = x → du = dx

— dv = cos(x) dx → v = sen(x)

Substituindo: x·sen(x) − ∫ sen(x) dx

— ∫ sen(x) dx = −cos(x)

∫ x · cos(x) dx = x·sen(x) + cos(x) + C
Exercício 9
Calcule ∫ ln(x) dx

Usa-se integração por partes. Embora pareça ter só um fator, reescrevemos como ln(x) · 1:

— u = ln(x) → du = 1/x dx

— dv = dx → v = x

Aplicando: x·ln(x) − ∫ x · (1/x) dx = x·ln(x) − ∫ 1 dx

∫ ln(x) dx = x·ln(x) − x + C
Exercício 10
Calcule ∫ x · eˣ dx

Usa-se integração por partes:

— u = x → du = dx

— dv = eˣ dx → v = eˣ

Aplicando: x·eˣ − ∫ eˣ dx = x·eˣ − eˣ

∫ x · eˣ dx = eˣ(x − 1) + C
